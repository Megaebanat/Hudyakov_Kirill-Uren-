# uikit — независимая UI-библиотека

Самостоятельный Flutter-пакет с собственным жизненным циклом и версией
(`1.0.0`): цвета, типографика, тема и переиспользуемые компоненты интерфейса
со всеми состояниями. Не содержит бизнес-логики.

## Характеристики независимого модуля

| Характеристика | Реализация |
| --- | --- |
| Изолированность | отдельный проект `packages/uikit` со своим `pubspec.yaml` |
| Повторное использование | подключается к нескольким приложениям (`app`, `storybook`) |
| Независимое версионирование | `version: 1.0.0` (semver) |
| Инкапсуляция | наружу — только `lib/uikit.dart` (публичный API) |

## Публичный API

**Тема и стили (DRY — единый источник истины):** `AppColors`,
`AppTypography`, `AppTheme`.

**Компоненты:**

| Компонент | Назначение |
| --- | --- |
| `AppButton` | кнопка во всех состояниях (primary/secondary/disabled/loading) |
| `AppTextField` | поле ввода (обычное/ошибка/пароль/иконка) |
| `AppSelect` + `AppBottomSheet` | селект с выбором в BottomSheet |
| `AppPagination` | постраничная навигация |
| `AppCard` | карточка |
| `AppBottomBar` | нижняя навигация с центральной кнопкой |
| `AppTimer` | таймер обратного отсчёта |
| `AppCheckbox` | флажок |
| `AppErrorBanner` | уведомление об ошибке (5 сек + закрытие) |

## SOLID/DRY

- **S** — каждый компонент отвечает только за своё отображение.
- **O** — вариации создаются параметрами, без правки компонента.
- **L/I** — единый контракт параметров, компонент получает только нужное.
- **D** — зависимости направлены на абстракции Flutter.
- **DRY** — цвета/типографика/тема в одном месте.
