# Спринты, ветки и Pull Request

Все модули конкурсного задания (А–Ж) реализованы. Работа ведётся в Git:
на каждый спринт создаётся отдельная ветка, по завершении — Pull Request в
`main` и закрытие PR (требование модуля Г для каждого спринта).

| Спринт | Ветка | Основные модули | PR |
| --- | --- | --- | --- |
| Спринт-1 | `sprint-1` | Модуль А (архитектура, документирование, логирование), Модуль Б (UIKit + StoryBook), Модуль Г | → `main` |
| Спринт-2 | `sprint-2` | Модуль В (библиотека сетевого слоя), Модуль Е (тесты 11 запросов), Модуль А/Г | → `main` |
| Спринт-3 | `sprint-3` | Модуль Б (Splash, приветствие, Регистрация, Вход, Landing, Schedule Game, Success), Модуль В (авторизация/регистрация/игра), Модуль Г (PDF, сессия, последний экран), Модуль Д (фото) | → `main` |
| Спринт-4 | `sprint-4` | Модуль Б (Discover Combats, Combat Information, Player Information, Statistics, Game Image), Модуль В, Модуль Г (кэш медиа, закрытие игры = поражение), Модуль Д (уведомления) | → `main` |
| Спринт-5 | `sprint-5` | Модуль Б (Game Circle), Модуль В (Game Circle), Модуль Г | → `main` |
| Спринт-6 | `sprint-6` | Модуль Ж: презентация, Яндекс Метрика, публикация в RuStore | → `main` |

## Модуль А — Архитектура и документирование (все спринты)

- [x] Каждый класс верхнего уровня имеет doc-комментарий с описанием
      ответственности (SRP), датой создания (`ДД-ММ-ГГГГ`) и автором.
- [x] Публичные методы описаны (назначение, параметры, возврат).
- [x] Нетривиальные алгоритмы (> 5 строк) снабжены построчными комментариями
      (напр. `CircleGameViewModel._buildCircles`, детерминированная раскладка
      `ImageGameViewModel`).
- [x] Логирование DEBUG/INFO/ERROR, единый формат `[Тег]: Событие — Детали`.
- [x] Обязательные точки: жизненный цикл экранов (INFO), сетевые операции
      (старт INFO → успех DEBUG → ошибка ERROR), критические кнопки (INFO),
      каждый `try-catch` (ERROR).

## Модуль Б — Вёрстка

- Спринт-1: цвета, типографика/тема, поле ввода (все состояния), Select с
  BottomSheet, кнопка (все состояния), Pagination, карточка, Bottom Bar,
  Timer, Checkbox + отдельное приложение **StoryBook**.
- Спринт-3: SplashScreen, три приветственных экрана (только при первом
  запуске, с пропуском), Регистрация (скролл + фиксированный «Create Account»,
  проверка email `name@domainname.ru`, показ пароля), Вход, Landing Screen
  (анимированное боковое меню, закрытие свайпом/крестиком, центральная кнопка
  → Schedule Game), Schedule Game (нативные пикеры даты/времени) → Success.
- Спринт-4: Discover Combats, Combat Information (вход в игру без соперника),
  Player Information, Statistics (THIS WEEK EARNINGS, Played Games —
  синий «Круг» / красный «Картинка», Scheduled Games), Game Image.
- Спринт-5: Game Circle (сборка кругов от большего к меньшему),
  авто-завершение и определение победителя.

## Модуль В — Клиент-серверное взаимодействие

- Спринт-2: отдельная библиотека `packages/network` — модели сервера,
  сетевой клиент, запросы, обработка ошибок; 11 эндпоинтов.
- Спринт-3/4/5: все экраны работают через абстракцию библиотеки; ошибка
  сервера или отсутствие сети → уведомление с текстом ошибки на 5 секунд с
  принудительным закрытием по кнопке.
